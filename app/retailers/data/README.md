`zip_centroids.csv` is the 2023 US Census ZCTA Gazetteer (public domain): ZIP Code Tabulation
Area internal point latitude/longitude, 4 decimals. Source:
https://www2.census.gov/geo/docs/maps-data/data/gazetteer/2023_Gazetteer/2023_Gaz_zcta_national.zip
Used only to rank retailer stores by distance from a ZIP code (see `app/retailers/zipmatch.py`).
